.. _modules.parser:

VCF parsing
-----------

Parsing site-frequency spectra from VCF files, with support for versatile stratification.

The parser is provided by the standalone `sfsutils <https://github.com/Sendrowski/SFSUtils>`_
package and remains importable directly from ``fastdfe`` (``from fastdfe import Parser``). See the
full API reference in the `sfsutils documentation <https://sfsutils.readthedocs.io/en/latest/modules/parser.html>`_.
