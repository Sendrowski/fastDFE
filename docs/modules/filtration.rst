.. _modules.filtration:

VCF filtration
--------------

Filtering VCF sites prior to parsing (e.g. coding sequences, poly-allelic sites, CpG contexts).

These classes are provided by the standalone `sfsutils <https://github.com/Sendrowski/SFSUtils>`_
package and remain importable directly from ``fastdfe`` (``from fastdfe import Filterer``). See the
full API reference in the `sfsutils documentation <https://sfsutils.readthedocs.io/en/latest/modules/filtration.html>`_.
