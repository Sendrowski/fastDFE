.. _modules.annotation:

VCF annotation
--------------

Ancestral-allele and site-degeneracy / synonymy annotation of VCF sites.

These classes are provided by the standalone `sfsutils <https://github.com/Sendrowski/SFSUtils>`_
package and remain importable directly from ``fastdfe`` (``from fastdfe import Annotator``). See the
full API reference in the `sfsutils documentation <https://sfsutils.readthedocs.io/en/latest/modules/annotation.html>`_.
